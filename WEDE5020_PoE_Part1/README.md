## How to run
Open `index.html` in a web browser. No server or framework is required.

## Before submission
- Replace the sample business address, phone number, email and prices with the details supplied by your assignment/lecturer.
- Replace the local SVG illustrations with your own licensed bakery photographs if the brief requires real photographs.
- Check every navigation link.
- Test the form on desktop and mobile.
- If the assignment requires a hosted/live form, connect the form to the approved service or backend.
- Add your student name, student number and any required declaration/readme information according to your module instructions.
